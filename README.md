# BET — Roulette francese

Simulatore gratuito e senza denaro reale. La pagina usa `crypto.getRandomValues()` con rejection sampling per estrarre in modo uniforme uno dei 37 numeri da 0 a 36.

## Funzioni

- roulette europea/francese a zero singolo (0–36);
- generazione uniforme tramite Web Crypto API e rejection sampling;
- tavolo con pieni, dozzine, colonne e chance semplici;
- fiches virtuali da €2, €5, €10 e €50;
- deposito, bilancio della sessione, storico e ripetizione della puntata.

Il progetto funziona interamente nel browser e non utilizza denaro reale, servizi a pagamento o raccolta dati.
